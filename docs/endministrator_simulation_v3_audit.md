## 市販品と同等と判定できない理由

1. 3D布メッシュは2D型紙を裁断・縫製して作ったものではない。型紙A/B/Cの縫い目の荷重やパネル同士の脇端を、今回の布シミュレーションは計算していない。
2. 生地の面密度・伸び・曲げ・摩擦・厚みを実測していない。販売者は素材群を「Faux Leather + Yarn + Knitted」と記載するが、各部位の物性値や内部の芯材は公開していない。3つの仮定値から特定商品の落ち感を認証できない。
3. 見返し・縁取りは表面追従するが、縫い線を共有する物理モデルではない。硬質小物と垂れ飾りは独立したままで、静止した小物と布の距離は固定強度や装着安全性の測定ではない。
4. 腕上げ、歩行、着座、着脱反復、肌への接触、縫い目や留め具の耐久試験をしていない。側面・背面の3D形状は正面イラストからの推定を含む。
5. 市販セットの写真には部品一覧と着用見本があるが、実物同士を同じ照明・体型・素材条件で比較した写真はない。

したがって現時点の判定は**「型紙の一部の接合と静止布落ちを検査済み。市販品同等は未検証」**である。画像だけから全項目を仮想試験し、実物比較と同じ結論へ置き換えることはできない。
