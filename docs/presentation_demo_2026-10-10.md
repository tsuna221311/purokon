# 2026-10-10 発表用固定入力デモ

この3件は発表時の再現性を確保するための、事前にパーツ構成を確認した固定入力である。
画像理解APIが原画や3面ラフから自動的に同じ構成を判定した実証ではない。

共通採寸（cm）：バスト83、ウエスト66、ヒップ91、身長158、袖丈52、肩幅37。
公開デモの「発表用・固定入力の3例」で対象を押すと、現在の入力を置き換えて
手動構成モードから生成する。過去の画像・補正・自由パネルを混ぜない。

| 例 | 内蔵構成 | 注意点 |
|---|---|---|
| 管理人（女性） | コート、袖、非対称裾パネル等 | 背面・側面、金具、素材、実布の動作強度は未確定 |
| 初音ミク（定番衣装） | 上身頃、プリーツスカート、布ストラップ | ネクタイ、腕カバー、意匠印刷は別工程 |
| オリジナル青いドレス | 丸首、直線袖、フレアスカート | 3面図は新規の模式ラフ。着脱用の開きは未設計 |

各例について、生成後の縫い線・合印などのデジタル検査で停止項目がないことと、
PDF/SVGのダウンロードを自動テストする。これは実布の仮縫い・着脱・耐久性の
合格を意味しない。青いドレスの3面ラフは
`web/static/demo/blue_dress_three_views.svg` にあり、編集可能なSVGである。

会場用のオフライン予備データは、まだ存在しない絶対パスを指定して生成する：

```powershell
python scripts/build_presentation_demo.py "C:\path\to\new-demo-output"
```

生成先の `manifest.json` に各例のファイル名と未検証項目が記録される。
裁断する場合は、A4印刷の100%校正、紙での接合確認、実布の仮縫いを別途行う。
