# 展示用三面図4枚と固定型紙の対応

展示用に制作した下記4枚のPNGについてのみ、ファイルのSHA-256が完全に一致し、
採寸が胸囲83・ウエスト66・ヒップ91・身長158・袖丈52・肩幅37cmで、
型紙に影響する設定が既定値の場合、検査済みの固定型紙を返す。
ファイル名だけの一致や、似た画像の判定ではない。再保存・圧縮・トリミング
された画像、別の採寸値、補正設定を入力した場合は通常の画像生成経路となる。

| 三面図 | 固定型紙に含む布部品 | 固定型紙に含まないもの |
| --- | --- | --- |
| 紺のテーラードコート | 身頃・袖・フレア下部・衿・袖口・パンツ、左右の外付けポケットとフラップ、布ベルト・通し | ダブルボタンの打ち合わせ、バックル・パイピングの実物仕様 |
| 翡翠色のケープ付きジャンプスーツ | 身頃・ワイドパンツ・衿・帯、片肩ケープと肩タブ2枚 | 留め具の実物仕様、斜め前開き線・脇の配色 |
| テラコッタ色の巻き衣装 | Vネック身頃・袖・巻きスカート・帯、左右の結びひも、白い袖口フレア2枚 | 斜め裾の確定、白い内スカートの実物仕様 |
| 苔色フードジャケットと橙色スカート | 前開き身頃・袖・フード・袖口・別体スカート・帯、左右の胸ポケットとフラップ | 裾リブ・ドローストリングの実物仕様、前ボタンの開き仕様 |

4件とも縫い線・裁断線、合印・布目線、既知の縫い合わせ長、A4配置を含む
`production_quality_report`がデジタル検査を通過し、未配置部品と
`compatibility_warnings`は0件。各固定例のPDF・SVG・DXF・仕様書PDFは
`web/static/demo/booth_patterns_v2/`に保存する。別布の裁断輪郭は各PDF・SVG・DXF、
仮の取付け位置と手順は仕様書PDFに収録する。結果画面には画像理解APIを
使用していないことと、事前に決めた構成であることを明示する。

追加部品は縫い代込みで出力し、生成枚数・外接寸法を構築時に検査する。
ポケット上辺／フラップは左右各0.5cm出す設計、ケープ上端は13cmで
3cm・9cmの2点留めを仮置きした。これらの取付け位置は原画の縮尺から
実測したものではなく、紙模型で調整する設計初期値である。

**この検査が保証しないこと:** 原画の全装飾の再現、別布の取付け位置の正しさ、
袖口フレアのギャザー配分、ケープの動作可否、金具と縫付け強度、生地の落ち感・伸び、
着脱・動作時の強度、実寸印刷後の貼り合わせ、実布での仮縫い。
固定型紙は裁断用の最終承認ではなく、紙上検討のための初稿である。

再生成する場合は `scripts/build_booth_demo.py` に新しい絶対パスを渡し、
既存の成果物を自動上書きしない。原画PNGは `tests/fixtures/booth_sheets/` に保存し、
4つの完全一致・設定変更での不一致・PDF/SVG/DXFのダウンロードを
`tests/test_booth_prepared_patterns.py` で検査する。
