# PatternForge 公開デモの配置

この構成は審査員向けの無料・匿名デモ専用です。会員登録、決済、組織、APIキーは無効です。一般公開の商用サービスとしては利用しないでください。

1. このブランチを GitHub に push する。
2. Render で **New → Blueprint** を選び、GitHub の `tsuna221311/purokon` を接続する。リポジトリ内の `render.yaml` を読み込ませる。
3. 画面上で `patternforge-demo` が **Free** であること、追加の有料リソースがないことを確認してから配置する。支払方法を求められる場合や費用が表示された場合は承認せず中止する。
4. 発行された `https://...onrender.com/healthz` が `{"ok":true}` を返すか確認し、トップページで型紙を1件生成し、PDFとSVGをダウンロードできるか確認する。

`SECRET_KEY` は Render が生成します。鍵の値を Git に追加しないでください。HTTPS Cookie と公開デモ制限は環境変数で有効化します。

**重要:** Free プランではアイドル時の休止・起動待ちが発生します。ディスクは永続化されません。SQLite、アップロード、生成物は休止・再配置・再起動時に消える可能性があります。秘密資料や個人情報を入力しないでください。実布での仮縫いや市販品同等の品質は未確認です。明朝の審査員向けデモで使う前に実際の公開URLから再確認してください。

Render に支払方法が登録済みの場合、無料枠を超えた帯域・ビルド時間には追加課金が生じ得ます。Render の利用量と支出制限も確認してください。支払方法がない場合は、超過時にサービスやビルドが停止されます。
