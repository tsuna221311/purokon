# PatternForge 公開デモの配置

この構成は審査員向けの無料・匿名デモ専用です。会員登録、決済、組織、APIキーは無効です。一般公開の商用サービスとしては利用しないでください。

1. このブランチを GitHub に push する。
2. Render で **New → Blueprint** を選び、GitHub の `tsuna221311/purokon` を接続する。リポジトリ内の `render.yaml` を読み込ませる。
3. 画面上で `patternforge-demo` が **Free** であること、追加の有料リソースがないことを確認してから配置する。支払方法を求められる場合や費用が表示された場合は承認せず中止する。
4. 発行された `https://...onrender.com/healthz` が `{"ok":true}` を返すか確認し、トップページで型紙を1件生成し、PDFとSVGをダウンロードできるか確認する。

`SECRET_KEY` は Render が生成します。鍵の値を Git に追加しないでください。HTTPS Cookie と公開デモ制限は環境変数で有効化します。

**重要:** Free プランではアイドル時の休止・起動待ちが発生します。ディスクは永続化されません。SQLite、アップロード、生成物は休止・再配置・再起動時に消える可能性があります。デモ画面の「この端末に保存」は明示操作でフォーム入力のみをブラウザの localStorage に保存します（画像なし）。「プロジェクトファイルを保存」はフォーム入力とPNG/JPEG/WebP/GIF画像を端末のJSONファイルに書き出します（画像合計10MBまで）。どちらにも生成済みPDF/SVG/DXFは含まれないので、生成後すぐに個別ダウンロードしてください。ブラウザデータの削除・端末ファイルの紛失には耐えません。秘密資料や個人情報は入力せず、保存ファイルを共有する場合は採寸値・画像の含有に注意してください。実布での仮縫いや市販品同等の品質は未確認です。審査員向けデモで使う前に実際の公開URLから再確認してください。

「衣装画像を探す」は入力後500msでOpenverseの画像検索APIへ検索語を送ります。画像候補と作者・ライセンス・元ページを表示し、利用者が選んだ場合だけ低解像度のサムネイルを正面資料へ追加します。公式設定画や対象衣装との一致は保証されません。Openverse自身もライセンス情報の正確性を保証しないため、利用者は元ページで確認してください。Openverseに画像がないキャラクターは手元の正面・背面資料をアップロードしてください。検索APIが応答しない場合でも、内蔵の形状プリセットと手元の画像アップロードは利用できます。生成用の高解像度資料が必要なら、権利を確認して原画像を別途用意してください。

検索結果の「この画像からラフを試す」は選んだ画像を正面資料に追加し、採寸確認と生成ボタンを表示します。選択だけでは1日の生成枠を消費しません。採寸は初期値のまま使わず、着用者の値に直してください。「この画像と採寸でラフ型紙を生成」を押した時点で生成が始まります。画像理解APIが未設定の場合は画像の衣装固有の形を解析できず、簡易判定のラフとなります。背面がない画像では背中の形も推定です。

Render に支払方法が登録済みの場合、無料枠を超えた帯域・ビルド時間には追加課金が生じ得ます。Render の利用量と支出制限も確認してください。支払方法がない場合は、超過時にサービスやビルドが停止されます。
