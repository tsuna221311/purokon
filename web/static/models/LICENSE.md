# Bundled default avatar

`default-avatar.vrm` is `vroid/beta/HairSample_Female.vrm` from
[`madjin/vrm-samples`](https://github.com/madjin/vrm-samples).

The [VRoid FAQ](https://vroid.pixiv.help/hc/en-us/articles/4402614652569-Do-VRoid-Studio-s-sample-models-come-with-conditions-of-use)
explicitly lists `HairSample_Female` among its CC0 sample models.
The model is bundled only as the local default fitting avatar; users can replace
it with their own VRM or GLB file from the viewer.

The VRM loader is `@pixiv/three-vrm` 3.5.5, licensed under the MIT License.
Its license text is stored at `web/static/vendor/THREE_VRM_LICENSE`.
